CoordFinder Documentation

For CoordFinder version

Parse a text and extract as many coordinate pairs as possible irrespective of the format of the coordinates. These points can be retreived as numbers, reprojected, formatted as text output, grouped by line breaks etc.

Basic demo:

point = CoordFinder.pointIn(Testdata)

Usage

Include coordfinder.js. Also include proj4js if support for any other reference systems than WGS84 (latitude/longitude) is needed.
Then call one of the CoordFinder static methods pointIn, pointsIn or groupsIn with a text.

<script src="path/to/proj4.js"></script> <script src="path/to/coordfinder.js"></script> ... var point = CoordFinder.pointIn(text); var points = CoordFinder.pointsIn(text); var groups = CoordFinder.groups(text);

Class: CoordFinder

Main class for the coordinate lookup, returns are mainly one or many Point objects.

For most uses the three static functions will do all that is needed. To get log info, tweak parsing sensitivity etc create an instance of CoordFinder instead.

CoordFinder Methods

Main "class" for finding coordinate pairs (points) in a text.

Static CoordFinder.pointIn(text): Get First Point

Simple static call to just find and return first possible point.
var point = CoordFinder.pointIn(text); if ( point ) { var lat = point.latitude(); var long = point.longitude(); var latlong = point.asText(); } Results when used on Testdata: lat: long: latlong:

Static CoordFinder.pointsIn(text): Get All Points

Static call to find and return all possible points.

var points = CoordFinder.pointsIn(text); var noOfPoints = points.length; var latlongs = ""; for ( var i = 0; i < noOfPoints; i++ ) { // Using options on asText to format output latlongs += points[i].asText({format: 'degreesandminutes'}) + "\n"; } Results when used on Testdata: noOfPoints: latlongs:

Static CoordFinder.groupsIn(text): Get All Points in Groups

Static call to find and return all possible points as an Array of Point Arrays. The Points are grouped by text lines without points. Empty lines is one example of such group delimiters. Useful for extracting separate polylines or polygons from the input text.

Note: this may return a different number of points than .pointsIn.

var groups = CoordFinder.groupsIn(text); var noOfGroups = groups.length; var latlongs = ""; for ( i = 0; i < groups.length; i++ ) { var points = groups[i]; latlongs += "Group " + i + ": \n"; for ( j = 0; j < points.length; j++ ) { latlongs += points[j].asText() + "\n"; } } Results when used on Testdata: noOfGroups: latlongs:

CoordFinder Instance Methods

.parse(text, {grouping: true}): Group Hits

The instance method implementation of the Static CoordFinder.groupsIn() above, which gives access to more options.

var groups = new CoordFinder().parse(text , {grouping: true}).groups(); var noOfGroups = groups.length; var latlongs = ""; for ( i = 0; i < groups.length; i++ ) { var points = groups[i]; latlongs += "Group " + i + ": \n"; for ( j = 0; j < points.length; j++ ) { latlongs += points[j].asText() + "\n"; } } Results when used on Testdata: noOfGroups: latlongs:

.points({rating: level}): Selecting points using a rating threshold

To select the number of points returned use the rating option for .points or .groups. This can be used for creating a dropdown or slider for showing less or more points.
The rating of a point is a decimal value between 0.0 and 1.0 indicating some sort of probability that a point found by parsing in fact is a valid point. Lower values gives a more forgiving approach and thus potentially more points.
Default rating level for .points() is 0.5.
To get an array of all rating levels found in all points after .parse() call .foundRatings().

var coordFinder = new CoordFinder(text); var ratings = coordFinder.foundRatings(); var points = coordFinder.points({rating: }); ...use points... Results when used on Testdata: ratings[]: Found

.log(): Get Log Info

To get a parse log create an instance of CoordFinder and call the parse() method instead if the static methods above.

var log = new CoordFinder().parse(text).log(); Results when used on Testdata: log:

Class: CoordFinder.Point

Consists mainly of two Coordinate objects, N and E, and a number of methods

.asText() Output Options

The asText() result can be tweaked if necessary using more options:
// options (with defaults first): // { // format:'', 'degrees', 'degreesandminutes', 'degreesminutesandseconds' // directionLetter: 'none', 'before', 'after': Where to place N, E etc // compact: false To remove spacing between N, E etc and coordinate values for more compact layout // decimals: 'default', 'auto', 0 to 10 // Number of characters used for the decimal part, through rounding or zero padding // 'default' to get enough decimals to keep maximum error in coordinates to roughly a meter // 'auto' to use number of decimals enough to keep below the maximum error from the parsed coordinate input text // localized:true, false: Control decimal separator (point or comma) // } var point = CoordFinder.pointIn(text); if ( point ) { var defaultFormat = point.asText(); var inDegrees = point.asText({format: 'degrees'}); var inDegreesAndMinutes = point.asText({format: 'degreesandminutes'}); var inDegreesMinutesAndSeconds = point.asText({format: 'degreesminutesandseconds'}); var inCustomFormat = point.asText({directionLetter: 'before', symbols: false, compact: false, decimals: 4, localized: false}); } Results when used on Testdata: defaultFormat: inDegrees: inDegreesAndMinutes: inDegreesMinutesAndSeconds: inCustomFormat:

.reprojectTo: Project Found Coordinates to other Coordinate Reference Systems

Reproject a found coordinate pair to one using refsys constants in namespace CoordFinder.RefSys.

var refsys = var refsysName = refsys.name; var refsysEPSGCode = refsys.code; var points = CoordFinder.pointsIn(text); var coordinatePairs = ""; for ( var i = 0; i < points.length; i++ ) { var reprojectedPoint = points[i].reprojectTo(refsys); if (reprojectedPoint) coordinatePairs += reprojectedPoint.asText() + "\n"; else coordinatePairs += "-\n"; } Results when used on Testdata: refsysName: refsysEPSGCode: coordinatePairs:

.textBefore, .originalText, .textAfter, .context: Get the context and its sub parts of where the Point was found

var point = CoordFinder.pointIn(text); if ( point ) { var textBefore = point.textBefore(); var originalText = point.originalText(); var textAfter = point.textAfter(); var context = point.context(); } Results when used on Testdata: textBefore: originalText: textAfter: context:
